English Translation:

Instructions:
Open the images in "swap_body" with an image editor (preferably one that supports layers), then load the desired statue sprite and adjust it to the same position as the template. The size does not need to be the same as the template's; it is only necessary for the new statue's size to be consistent across all three images. Use these definitions as a guide:
swap_body-1: When the player moves forward and the camera views their back.
swap_body-2: When the player moves backward and the camera views their face.
swap_body-3: When the player moves to the right, the sprite is inverted (or flipped/mirrored) when the player moves to the left.
Once the images are ready, save them with the same name and dimensions, as a 32-bit depth PNG file, in a folder named "swap-body" and place it next to the "swap" SCML file. The SCML file must not be modified.

IMPORTANT: The same SCML must be used for all parts; only the name of the .scml file should be changed to match the name and material of the part being built. Do not delete noimage.png under any circumstances.

Japanese Translation:

手順:
「swap_body」内の画像を画像エディタ（できればレイヤーをサポートしているもの）で開き、目的のスタチュースプライトを読み込み、テンプレートと同じ位置に調整します。サイズはテンプレートと同じである必要はありません。新しいスタチューのサイズが3枚の画像すべてで一貫していることのみが必要です。以下の定義をガイドとして使用してください:
swap_body-1: プレイヤーが前進し、カメラが背中を見ているとき。
swap_body-2: プレイヤーが後退し、カメラが顔を見ているとき。
swap_body-3: プレイヤーが右に移動するとき、スプライトはプレイヤーが左に移動するときに反転（またはフリップ/ミラー）されます。
画像が準備できたら、それらを同じ名前と同じ寸法で、32ビット深度のPNGファイルとして「swap-body」というフォルダに保存し、「swap」SCMLファイルの隣に配置してください。SCMLファイルは変更してはいけません。

重要: すべてのパーツで同じSCMLを使用する必要があります。作成しているパーツの名前と素材に合わせて、.scmlファイルの名前のみを変更してください。いかなる状況でも noimage.png を削除してはいけません。
